## Domain and the acceptance argument

The native entry point uses the actual non-template
`caterpillar::xag_fast_lowt_mapping_strategy` or default-ASAP
`caterpillar::xag_low_depth_mapping_strategy`. There is no Bennett fallback.
The admitted build has `low_tdepth_AND=false`; emission is static exact
X/CNOT/Toffoli. ALAP, n-ary networks, dirty initial computation scratch,
measurement-assisted AND cleanup and other strategy variants are excluded.

Before Boolean tables, Python checks inputs<=6, stored nodes<=64, outputs<=16,
raw width<=128 or the smaller integer budget, steps<=128 and gates<=4096.
Node IDs are exactly consecutive; PIs are positional IDs 1 through n; constant
zero is explicit. Non-PI nodes are reachable binary AND/XOR gates with distinct
earlier nonconstant fanins. XOR edges are uncomplemented; truth strings and all
edge/output polarities are checked. Serialized graph rows may be DFS-ordered;
the validated node IDs, not list position, determine construction order.
Boolean and floating substitutes for semantic integer indices reject.

Native network caps precede strategy and LHRS containers; action count is checked
before LHRS, and each physical allocation enforces width. Python bounds the
input source file at 2,000,000 bytes and the native process at five seconds.
Parsing, output selection and optional refactoring occur before the network
gate. Neither this domain nor terminal RSS supplies a hard parsing/preprocessing
memory guarantee. The certificate concerns the returned final graph. General
source/parser, output-selection and preprocessing CEC are not certified.

The following argument is separate from the sequential two-cone theorem:

1. Independent graph tables contain every assignment of the n declared inputs:
   each `f_n` is an integer mask with at most 64 bits. Initialize physical `W[q]`
   with PI masks and zero clean workspace. Each replayed controlled X updates
   its target by the exact conjunction of current physical control functions,
   including polarity. Distinct controls and target/control separation are
   required. Induction on the emitted gates therefore makes `W[q]` the actual
   physical wire function, regardless of the strategy's labels or ordering.
2. Address stacks, active nodes and the LIFO free list are tracked separately.
   Resolving the skipped in-place target is an address operation; every actual
   parity-control read checks its physical function against `f_n`. Central
   controls are checked against their cone roots, with cone parity independently
   compared to the graph. An existing stack entry alone cannot establish value.
3. Compute prepares copies for the whole level, then prepares each node's cones,
   performs the central operation, restores parity in reverse order, restores
   stacks, and finally removes copies. Each frame compares every prior wire and
   stack, allowing only the computed target to change; new residual scratch must
   be zero. Every action boundary requires distinct correct active values and
   zero on every other physical wire. Temporarily held copy parities within a
   level are accounted for by frames, rather than falsely required to be zero.
4. Copy release requires zero, no live top alias and no duplicate free entry;
   reuse checks zero again. Pinned `uncompute_level` reverses the level, zeros
   central targets and pops their mappings, but **does not release those targets**.
   Replay matches that behavior. Zeroed-but-unreleased allocation cannot be
   counted as freed scratch or a free inverse AND. Singleton and empty frontiers
   follow the actual branch behavior; the tests are not substituted for these
   checks on a later schedule.
5. Before output preparation, precisely the PI/used-constant/output-driver set
   is active, with correct values and clean other workspace. A first complemented
   PI output may flip a raw input. Duplicate outputs copy the first physical
   value and correct polarity relative to its first occurrence. Each final
   output is checked against its independently evaluated function.
6. Acceptance requires typed JSON equality with the complete actual gate list,
   exact input/output maps and physical width. Thus this physical-value proof
   applies to the circuit that is constructed, not a different replay circuit.
   The request/strategy handshake precedes validation and circuit construction.

These are checked obligations for **any accepted finite level schedule** in the
specified domain. They establish soundness without claiming every native schedule
will satisfy them, or extending a sequential schedule theorem to level actions.
Failures reject instead of silently acquiring a certificate. The finite function
argument does not extend beyond six inputs without a separately reviewed proof.

All actual primitives have phase +1. If raw computation is U and its outputs
are f(x), the actual `U; copy; U.inverse()` gives
`|x,0,y> -> |x,0,y XOR f(x)>`; the selected-Z wrapper gives
`|x,0> -> (-1)^f_j(x)|x,0>`. This holds on the clean computation subspace,
including reference-entangled inputs by linearity. It does not promise raw input
restoration after complemented output preparation, dirty-workspace action or
correctness of an independently substituted inverse/lowering.
