# Research context

[The original roadmap](roadmap.md) records the paper revision ideas, lowering strategies, and conditional-workspace questions that motivated the newer Boolean studies. It is retained as written.

The refactor provides reusable synthesis, validation, and workspace-analysis components. It does not implement automatic workspace borrowing, new synthesis algorithms, a hardware study, or a new architecture-cost model.

Publication diagrams and slides are collected under [documentation assets](../assets). Historical experiments and paper comparison outputs are indexed in [the archive](../../archive/README.md). Local manuscript files remain in the ignored root manuscript directory.
