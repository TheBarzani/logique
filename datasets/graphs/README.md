# Graphs

Generated by `tools/build_graph_tiers.py`; do not edit by hand. The manifest
(`manifest.json`) holds every column below and more for each graph, and
`witnesses.json` holds one proper coloring per graph.

## Layout

| Folder | What it holds |
| --- | --- |
| `discovery/` | The nine graphs of the rejected manuscript: the **discovery set**, on which every finding up to 26 November 2026 was made. Their tiers are listed below. |
| `small/<class>/` | **Small tier**: structured graphs whose data register has at most 24 qubits, simulated exactly. |
| `medium/<class>/` | **Medium tier**: graphs whose colorings can be counted within the study's budget, so the complete search is priced exactly. |
| `large/<class>/` | **Large tier**: graphs whose colorings cannot be counted; compared per Grover iteration. |
| `teaching/` | Tutorial inputs and the format template (`template.col`). |
| `legacy/` | Historical and development inputs outside the study. |

Every graph outside `discovery/` belongs to the **confirmation set**. Each file records its color count k in an `x colors` line. ω is the clique number: when ω = k, k colors are necessary, so k is the chromatic number.

## Classes

| Class | Description |
| --- | --- |
| paths | Paths; trees, so the edge-wise oracle has no slack. |
| cycles | Single cycles, even (two colors) and odd (three colors). |
| complete | Complete graphs. |
| petersen | The Petersen graph: triangle-free, three colors. |
| wheels | A hub joined to every vertex of a cycle; every triangle uses the hub. |
| complete-multipartite | Every vertex joined to every vertex of the other parts: the most triangles without larger cliques. |
| latin-squares | Rook's graphs: one clique per row and per column of an n by n grid; their n-colorings are the Latin squares of order n. |
| sudoku | Sudoku graphs: cliques for rows, columns and boxes. |
| grids | Square grids: bipartite with many cycles. |
| hypercubes | Hypercubes: bipartite and triangle-free. |
| planar-triangulations | Maximal planar graphs (map coloring): random vertex insertions followed by random edge flips; three colors exactly when every degree is even, four otherwise. |
| interval-graphs | Overlaps of random intervals (scheduling and register allocation): the chromatic number equals the clique number. |
| planted-vertices | Planted k-colorings with balanced classes and cross-class edges kept with probability 0.5, varying the number of vertices. |
| planted-density | Planted 3-colorings of 16 vertices, varying the cross-class edge probability (0.5 is planted_n16_k3_p50 in planted-vertices). |
| planted-colors | Planted k-colorings of 24 vertices with a planted k-clique, so that the chromatic number is exactly k, for every k from 2 to 20. |
| queens | Queen graphs (DIMACS): cliques along rows, columns and diagonals. |
| mycielski | Mycielski graphs (DIMACS): triangle-free with growing chromatic number. |
| random | Random graph DSJC125.1 (DIMACS): edge probability 0.1. |
| leighton | Leighton graph le450_5a (DIMACS): planted cliques, known chromatic number. |
| insertions | Insertion graphs (DIMACS): Mycielski-like constructions. |
| book-characters | Characters of a novel joined when they appear together (Stanford GraphBase, DIMACS). |
| football-games | College football teams joined when they played (Stanford GraphBase, DIMACS). |
| city-distances | North American cities joined when closer than 250 miles (Stanford GraphBase, DIMACS). |
| zed-city | The Zed city problem of the IBM Quantum Hackathon 2019, posed as vertex coloring. |

## Sources

- **Generated graphs** (structured classes and planted families) are built by `tools/build_graph_tiers.py` from the construction and seed given in their origin and in the first line of each file.
- **DIMACS graph-coloring collection** (maintained by Michael Trick): [COLOR](https://mat.tepper.cmu.edu/COLOR/instances.html) and [COLOR02/03/04](https://mat.tepper.cmu.edu/COLOR04/). Each downloaded file keeps its original header, which names its author, and is checked against the SHA-256 recorded in the tool.
- **Stanford GraphBase**: D. E. Knuth, *The Stanford GraphBase: A Platform for Combinatorial Computing*, Addison-Wesley, 1993. The queen, book, football and city-distance graphs come from it through the DIMACS collection.
- **Original manuscript**: the complete graphs were written for it; the other discovery graphs come from the sources named in their origin.
